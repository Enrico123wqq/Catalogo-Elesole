# Template e riferimenti ENF

Questa cartella contiene file ENF utili come riferimento tecnico per campi prodotto, dati di pannelli, inverter, batterie o altri componenti fotovoltaici.

## Uso corretto

I file ENF aiutano a capire:

- campi tecnici ricorrenti;
- struttura dati prodotto;
- attributi importanti;
- normalizzazione tecnica.

## Uso scorretto

I file ENF non devono essere usati come tracciato import Odoo.

ENF serve per arricchimento e confronto tecnico, non per decidere le colonne del file Odoo.
