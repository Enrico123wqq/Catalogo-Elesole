# Reference templates

Questa cartella contiene i file modello ufficiali da usare come riferimento.

## Regola

I file in questa cartella sono golden master.

Codex deve leggere questi file e copiare struttura, colonne e ordine quando genera output compatibili.

## Sottocartelle

- `odoo/`: template ufficiali per import Odoo.
- `enf/`: esempi e database tecnici ENF utili per capire campi prodotto e struttura dati.

## Attenzione

Non usare file generati automaticamente come template ufficiali senza approvazione.
